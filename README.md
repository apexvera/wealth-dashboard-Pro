# Wealth Management Automation Dashboard (Ghana)

A professional **wealth management system dashboard** designed for Ghana-based investments.  
This project provides a **web app prototype** with automation flows, interactive charts, and API placeholders for Ghana financial platforms (Databank, Bamboo, Sarwa, Ecobank, MTN MoMo).

---

## 🚀 Features
- **Golden Split Overview**: Investments (62.5%), Reserve Fund (25%), Savings Buffer (12.5%).
- **Interactive Tables**: Max Profit vs Low Risk investments.
- **Automation Flows**: Daily, Monthly, Yearly routines with chart updates.
- **Visualization Hub**: Pie chart, line chart, heatmap for risk exposure.
- **Dual Mode Toggle**: Switch between **Mock Demo Mode** and **Live Data Mode**.
- **API Placeholders**: Ready for integration with Ghana platforms.
